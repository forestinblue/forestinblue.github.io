Range-Aware Uncertainty Calibration in Self-Supervised Monocular Depth

MSc thesis, 2026. Paper in preparation with Prof. Rui Huang.

Self-supervised depth models never see ground-truth depth, so their predicted uncertainty is never tied to actual error. I calibrate it without any ground-truth depth by training only the uncertainty head on residuals against classical stereo matching. This cuts near-range calibration mismatch by 83% compared with the original model.

LocalAggTR: Differentiable Voxelization for Weakly Supervised 3D Occupancy

Capstone project, 2025.

The Gaussian-to-voxel step in GaussTR is non-differentiable and dominates inference time. I replaced it with a differentiable Local Aggregation operator that passes occupancy gradients, giving 7.2 times faster inference with mIoU unchanged on nuScenes.

Point Cloud Density and 3D Object Detection

2025.

How does a 3D detector degrade when LiDAR density drops, and can upsampling recover it? With PointPillars on nuScenes-mini, voxel-grid downsampling kept one fifth of the points with only a 2.1% relative mAP drop, while upsampling recovered less than half of the loss from random sampling.

Geometric vs. Generative 3D Augmentation for Point Cloud Classification

2025.

Does text-to-3D generative augmentation help a point cloud classifier more than geometric augmentation? With PointNet on ModelNet40, geometric augmentation raised accuracy by 6.5%, while Point-E generated shapes lowered it.
